# 青聚點 AI 工具實作課程規劃
n8n × Codex × Cloudflare，從零打造課程查詢 AI 助理

## 課程簡介

本課程為青聚點設計，面向對 AI 工具有興趣但尚無程式背景的新手學員。
課程不從理論出發，而是以「動手做出一個真實可用的系統」為目標，
帶領學員在 16 小時內完成一套課程查詢 AI 助理——
使用者在網頁上輸入問題，系統自動比對向量資料庫並由 AI 整合回覆。

## 課程結構

### 模組一：n8n 基礎與 Google 憑證（4 小時）
從 AI 觀念建立切入，介紹 LLM 與 AI Agent 的差異、Prompt 設計六大規範，
以及用於結構化提問的 PSIO 框架（Purpose / Step / Input / Output）。
接著實際操作 n8n，以 Chat Trigger + AI Agent 節點建立第一個對話工作流，
最後完成 Google Cloud OAuth 憑證申請，串接 Gmail 與 Sheets API。

### 模組二：VSCode + Codex 前端開發（2.5 小時）
學習如何與 AI 模型協作寫程式：從直接描述需求到使用 PSIO 撰寫完整 prompt，
透過五個漸進式範例（靜態頁面 → 表單驗證 → 互動效果 → 假資料展示 → UI 優化）
建立前端開發的完整流程，課後以配色調整與假資料補充作為作業驗收。

### 模組三：整合應用與安全部署（9.5 小時）
以課程查詢系統為主軸進行端對端整合：
- 向量資料庫概念介紹（Embedding 原理、Qdrant 語意搜尋）
- 在 n8n 建立 Qdrant 知識庫並設計完整查詢工作流（含錯誤處理）
- 用 Codex 產生前端查詢介面並串接後端
- 加入 Cloudflare Worker 安全代理層（依版本深度不同）
- GitHub Pages 部署上線，成果展示

## 版本說明

本規劃依安全需求提供三個版本，課程核心內容相同，差異集中在模組三的安全部署深度。

### 原始版（11 節）
模組二保留獨立的對話課、前端課、資料清理課，模組三前端直連 n8n Webhook，
不含 Cloudflare 安全層。適合內部測試或自用工具情境。

### 基礎代理版（10 節）
採「組合二」調整：合併模組二的對話課與前端課（節省 0.5h），
移除資料清理課至課後作業（節省 1h），釋出時數加入 Cloudflare Worker 基礎安全設定（2h）。
內容涵蓋 Origin 檢查、CORS 處理、n8n Header Auth，
讓前端不再暴露 n8n URL，適合小型展示或同學互測情境。

### 正式上線版（10 節）
同樣採「組合二」，並進一步壓縮向量DB概念課（0.5h）與部署課（0.5h），
將釋出的 1.5h 全數投入 Cloudflare 完整安全架構（共 3.5h，6 個部分）：
安全架構全覽、Worker 代理、n8n Header Auth、Cloudflare Turnstile 人機驗證、
Rate Limit 與成本控管、Google Sheets 監控記錄與 Staging/Production 分離。
適合對外開放服務，有真實使用者的上線情境。

|------|--------|-----------|-----------|

| 模組二 | 4h（3 節） | 2.5h（合併 1 節） | 2.5h（合併 1 節） |
| 資料清理課 | 課堂 1h | 移至課後作業 | 移至課後作業 |
| 向量DB 概念 | 1h（完整） | 1h（完整） | 0.5h（壓縮版） |

| 部署 | 1.5h（含優化） | 1.5h（含優化） | 0.5h（純部署） |
| 成果展示 | 1h | 0.5h | 0.5h |

## 技術棧

| 工具 | 用途 |
|------|------|
| n8n | 自動化工作流與 AI Agent 編排 |
| VSCode + Codex | AI 輔助前端開發 |
| Google AI Studio API | Embedding 轉換與對話模型 |
| Qdrant | 向量資料庫，語意搜尋課程資料 |
| Cloudflare Worker | 後端安全代理層，隱藏 n8n URL |
| Google Cloud | Gmail / Sheets API 憑證 |
| GitHub Pages | 前端靜態頁面免費部署 |

- 無程式開發背景，但想了解 AI 工具實際應用的職場工作者
- 希望能獨立串接 AI 服務、建立自動化流程的初學者
- 對「AI 不只是聊天」有好奇心，想動手驗證想法的學員
